## Goal
Implement positive test count parsers for unittest and pytest (jest/vitest as experimental notes), verify newly added or modified test functions appear in runner output (relative to base_commit recorded at start), enforce standard locale flags (LC_ALL=C), and add benchmark vector V18.

## Constraints
- Python 3.8+ standard library only.
- Unittest and pytest output parsers tested against captured real-run seam sources.
- Newly added/modified test names determined from git diff against base_commit recorded at osr start.
- Non-verbose runner output flags missing test names and requires verbose flag or marks UNVERIFIED.
- Benchmark vector V18 includes control run and literal, disguised, and subtle variants.

## Do not
- Do not let runner output with 0 passed tests produce VERIFIED.
- Do not accept non-English runner output without locale-independent parsing.

## Definition of done
- tests/test_runner_parsers.py passes parser conformance tests.
- Benchmark vector V18 catches zero-test and unparsed runner outputs.
- osr verify T15 passes.
