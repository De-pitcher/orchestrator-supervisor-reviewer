## Goal
Support pluggable external language checkers in config.json and establish an automated adversarial evaluation benchmark suite.

## Inputs and context
- Enables external CLI checkers to report structured validation results.
- Builds an eval suite with seeded cheat attempts.
- Benchmarks detection rate across frontier and smaller models.

## Constraints
- Standard library core with pluggable runner interfaces.

## Do not
- Do not hardcode external language runtimes into the core CLI.

## Definition of done
- config.json allows declaring external checkers.
- Adversarial test benchmark calculates catch rate and false-positive rate.
- README.md includes verified benchmark results and version bumps to v0.2.
