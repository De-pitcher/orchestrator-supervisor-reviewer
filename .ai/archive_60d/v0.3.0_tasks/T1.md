## Goal
Declare every cross-boundary interface with its authoritative source at both plan and card levels.

## Inputs and context
- Roadmap Phase 1 specifications.
- `assets/PLAN.md` template.
- `scripts/osr.py` (`parse_plan`, `validate_card`, `cmd_plan_check`, `cmd_task_check`).

## Constraints
- Python 3.8+ standard library only.
- Cards that declare no seams must behave exactly as before.
- Heuristic checks warn, do not block.

## Do not
- Do not add a new `context_contracts` field; use `context_files`.
- Do not break existing cards without seams.

## Definition of done
- Seams table added to `assets/PLAN.md`.
- `seams:` field parsed in task cards.
- `plan-check` warns when external API/socket/queue/service mentioned without Seams table.
- `task-check` fails if seam authoritative source is missing from `context_files`.
- SKILL.md Rule 5 clarifies reading provider code via `context_files`.
- V10 benchmark condition (`seam_field_mismatch`) fails `task-check`.
