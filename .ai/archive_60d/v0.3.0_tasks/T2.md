id: T2
requirements: R2
depends_on: T1
allowed_files: assets/quality-review.md, scripts/osr.py, tests/test_osr.py

verify: python -m unittest discover -s tests -v

## Goal
Require reviewers to open and cite authoritative upstream definitions using the snippet checker.

## Inputs and context
- Roadmap Phase 2 specifications.
- `assets/quality-review.md`.
- `scripts/osr.py` (`cmd_review`, review citation parser).

## Constraints
- Python 3.8+ standard library only.
- Cards with no seams do not require the Seams section.

## Do not
- Do not accept citations only pointing to consumer files for declared seams.

## Definition of done
- Seams section in `assets/quality-review.md` template.
- Reviewer cites `@ <seam source path>:<line> "exact snippet"`.
- `osr review <task> quality` verifies citations and requires at least one per declared seam.
