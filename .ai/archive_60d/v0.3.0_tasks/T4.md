# T4: Conditional kinds and per-seam negative tests
id: T4
requirements: R4
depends_on: T1
allowed_files: assets/quality-review.md, scripts/osr.py, tests/test_osr.py, README.md
forbidden_files: 
context_files: .ai/PLAN.md, ROADMAP.md
verify: python -m unittest discover -s tests -v

## Goal
Enforce lifecycle, failure-path, and realtime checks only on tasks declaring matching kinds or seams.

## Inputs and context
- Roadmap Phase 4 specifications.
- `assets/quality-review.md`.
- `scripts/osr.py` (`cmd_review`, `cmd_verify`, `cmd_done`).

## Constraints
- Python 3.8+ standard library only.
- Cards without `kind: realtime` or seams do not require negative tests or the realtime appendix.

## Do not
- Do not add paperwork or checks to normal tasks.

## Definition of done
- Optional card field `kind:` supported.
- Realtime appendix added to `assets/quality-review.md` required only for `kind: realtime`.
- Card field `negative_tests:` requires one named test per seam covering unexpected upstream fields.
- `verify` checks named negative tests appear in recorded test output.
