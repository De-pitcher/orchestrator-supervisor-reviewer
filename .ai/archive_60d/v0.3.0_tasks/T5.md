- Review pack must contain no builder reasoning.

- Do not let unverified manual requirements pass audit without signoff.

- `review-pack` includes diff, card, criteria, seam table, authoritative source excerpts, and adversarial prompt.
- `Check: manual` with manual test script references supported in plan.
- `audit` shows un-signed manual requirements as UNVERIFIED (exit code 2).
