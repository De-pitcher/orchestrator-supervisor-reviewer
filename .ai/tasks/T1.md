## Inputs and context
- `scripts/osr.py` contains the current single-file implementation.
- All existing 15 tests in `tests/test_osr.py` must pass.
- New tests must verify --json output, exit codes, and ledger locking.

## Constraints
- Python 3.8+ standard library only.
- No third-party runtime dependencies.
- Maintain full backwards compatibility with existing CLI flags.

## Do not
- Do not touch files outside allowed_files.
- Do not add external runtime dependencies.
- Do not weaken, skip, or delete existing tests.

## Definition of done
- --json outputs valid parseable JSON across CLI commands.
- Documented exit codes (0=success, 1=user error, 2=gate rejection, 3=blocked, 4=integrity violation).
- Ledger write operations use file locking.
- pyproject.toml defines console_scripts entry point for osr.
- SKILL.md trigger description tightened and Iron Rule 10 wording cleaned up.
- All tests pass cleanly.
