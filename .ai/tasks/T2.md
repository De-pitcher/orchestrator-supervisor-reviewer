# T2: Red/Green evidence enforcement and cheat rejection
id: T2
requirements: R2
depends_on: T1
allowed_files: scripts/osr.py, src/**, tests/test_osr.py
forbidden_files: assets/**, references/**
context_files: .ai/PLAN.md, SKILL.md
verify: python -m unittest discover -s tests -v

## Goal
Enforce red-green verification where osr start captures a baseline and verify requires changed tests to fail before and pass after, rejecting cheat attempts.

## Inputs and context
- Requires stable CLI and modular architecture from T1.
- Catches cheats such as verify: true, tests that cannot fail, or assertion loosening.

## Constraints
- Standard library only.
- Minimize false positives on small projects.

## Do not
- Do not touch files outside allowed_files.
- Do not allow bypasses without human waivers.

## Definition of done
- osr start records pre-implementation test failure baseline.
- verify validates transition from failing to passing.
- Cheat attempts are detected and rejected.
- All unit tests pass.
