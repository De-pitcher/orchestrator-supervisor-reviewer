## Goal
Implement a hardened trust model requiring secret-backed human approvals, config hash locking, and external ledger anchoring.

## Inputs and context
- Protects against malicious or hallucinated agent approvals.
- Config hash inclusion in plan approvals voids approval upon config tampering.
- osr anchor registers ledger head externally.

## Constraints
- Standard library cryptography and hashing.

## Do not
- Do not store approval secrets in plain text within agent-readable paths.

## Definition of done
- Human approvals validate external approval secrets.
- Editing config voids active plan approval.
- osr anchor enables verifiable ledger anchoring.
- Adversarial test suite verifies rejection of forged approvals.
